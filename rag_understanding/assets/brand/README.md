# Context First AI brand assets

Copied from the Context First AI website repository, governed by
`Assets/Brand/BrandGuide_ContextFirstAI.md`.

| File | Upstream path | Use |
|---|---|---|
| `Logo_ContextFirstAI.png` | `Assets/Logo/` | App header and sidebar |
| `favicon-32x32.png` | `frontend/public/` | Browser tab icon |

`Logo_ContextFirstAI.png` is the rendition the live site uses. Note the
`Assets/Logos/` (plural) folder upstream holds different SVG variants — those
are NOT what production renders; do not substitute them.

The PNG has a baked-in `#1A1B1E` (Deep Space) background, which matches the
app background exactly, so it blends rather than showing as a box. Keep the
app background at `#1A1B1E` or the logo will show a visible panel.

Do not recolour, stretch, rotate or add effects (Brand Guide §7).
